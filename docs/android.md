# 短信转发（独立 Android App）

本项目「短信自动转发」的 Android 端，桌面名称“短信转发”，包名 `com.kidbuddy.smsforwarder`。支持 Android 10 及以上，提供可侧载的 APK，不依赖 GMS、不发送短信、零后端零统计。支持配置多个转发目的地（**飞书、企业微信、钉钉、自定义 HTTPS Webhook**）、多条独立过滤规则，并内置 **9 个常见电商/本地生活商家平台验证码模板**一键勾选。

## 使用

1. 在首页「转发设置」中进入**转发目的地**，点击**添加目的地**，选择平台并填写名称、HTTPS Webhook 地址和可选签名密钥：
   - **飞书**：`https://open.feishu.cn/open-apis/bot/v2/hook/...`，关键词可设为“短信转发”，启用签名校验时填写密钥。
   - **企业微信**：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`（无需签名密钥）。
   - **钉钉**：`https://oapi.dingtalk.com/robot/send?access_token=...`，关键词可设为“短信转发”，启用加签时填写 `SEC...` 密钥。
   - **自定义 Webhook**：任意合法 HTTPS 地址；发送 JSON `{"title":"短信转发","text":"...","timestamp":...}`，选填密钥时附带 `X-Webhook-Timestamp` 与 `X-Webhook-Signature` 请求头。
2. 在首页进入**转发规则**，点击**添加规则**，为规则命名、选择对应的转发目的地，并按需要勾选预置商家平台模板或自定义过滤条件（可创建多条规则，例如外卖验证码发飞书群、电商后台验证码发企业微信群、告警发钉钉群）。
3. 首次安装后在首页进入**权限与后台保活**，点**授予短信权限**，并在系统弹窗中允许。若弹窗未出现或开关置灰，请按下方[国产手机放行与保活 5 步排查](#国产手机放行与保活-5-步排查)处理。
4. 点首页顶部的转发开关开启**自动转发**，阅读并确认提示。点击**发送测试消息**并选择目的地验证连通性，再用另一部手机发普通短信验证完整链路。
5. （可选）多台手机转往同一个群时，在首页进入**本机号码 / 备注**，填写本机号码或门店备注（最多 48 字），消息中会附带 `接收手机：…`。只保存在本机，不申请电话或 SIM 权限。

从旧版升级安装（`adb install -r`）时，原有的飞书机器人配置和单条过滤条件会自动迁移为「默认飞书群」和「默认规则」，原有待发队列也会继续兼容发送。

收到新短信时，App 会依次评估所有**已启用**的规则：
- 一条短信若命中多条指向**不同目的地**的规则，会分别入队投递到各个目的地；
- 一条短信若命中多条指向**同一目的地**的规则，会自动去重，只向该目的地发送一次。

自动转发默认关闭，暂停期间短信不会补发。无需默认短信应用身份，不读取历史收件箱。彩信、RCS、通知消息不支持。地址与密钥默认隐藏，仅保存在本机应用私有目录，不写日志、不参与备份。

首页显示转发开关、开启前准备清单、最近动态与待发队列（含「重试发送」「清空队列」），以及「转发设置」中的转发目的地、转发规则、权限与后台保活、本机号码 / 备注入口。右上角外观按钮可选择浅色、深色或跟随系统。App 无需固定屏幕，可正常返回桌面，在后台等待新短信。

## 哪些短信要转发（预置模板与自定义规则）

### 预置 9 个常见商家平台模板（直接勾选）

在新建或编辑规则时，可以直接多选常见电商与本地生活商家平台模板（单条规则可多选发往同一群，也可建多条规则分流到不同群或不同 IM）：

| 分组 | 预置平台模板 |
| --- | --- |
| **本地生活 / 即时零售** | 美团（美团 / 开店宝 / 美团外卖）、淘宝闪购 / 饿了么、京东到家 / 京东秒送、抖音来客 |
| **电商 / 投放商家** | 淘宝 / 天猫 / 千牛、拼多多商家、小红书（千帆 / 聚光）、微信小店 / 视频号 |
| **通用保底** | 全部验证码（自动排除银行 / 扣款 / 转账等敏感词） |

预置模板默认采用**三段防误转语义**与**默认安全排除词**：
- **三段防误转语义**：`（所选平台关键词任一命中）AND（含验证码 / 动态码 / 校验码等字样）AND（含连续 4～6 位数字）`，避免带有 4 位数字的优惠券、营销通知或取餐码被误转。
- **默认安全排除词**：自动填入可编辑的防误转排除词（例如 `退订、回T、优惠、银行、扣款、转账`），防止资金敏感短信或广告误发到工作群；底层关键词和排除词全部透明可见，随时可按需微调。

### 通用模式与高级选项

如果不使用平台模板，也可以按通用过滤方式设置：

| 选择 | 保存后的效果 |
| --- | --- |
| 全部短信 | 不筛选，所有新短信都会转发；原有排除词和来源限制暂不生效，但配置保留。 |
| 验证码短信 | 正文同时含“验证码”和连续 4～6 位数字；保留已有排除词和来源限制。 |
| 验证码字样或数字 | 正文含“验证码”或有连续 4～6 位数字；订单编号也可能命中，保留已有排除词和来源限制。 |
| 自己设置 | 自行填写关键词、勾选数字条件，选择有一个符合即可或两项都符合。 |

需要额外限制时，展开可选项：
- **不转发这些内容**：填写不想转发的文字，例如“银行”。命中其中一个就不转发，优先于正文条件。
- **只转发这些号码**：不填写表示不限来源；可填完整号码或 `106*` 这样的开头，例如 `106*` 表示 106 开头的号码。多项可换行或用中英文逗号分隔。

规则页底部提供**试一条短信**和保存按钮，可在本地模拟任意号码与正文，立即查看命中哪些规则、原因以及是否会被转发（不保存、不发往外部、不入队）。规则列表页同样支持全局试算，一次看清一条短信会发往哪些目的地。

连续数字兼容全角；7 位及以上数字串不会截取匹配。关键词忽略字母大小写，每组最多 32 项，每项最多 64 字；号码规则最多 32 项，不按尾号模糊匹配。号码会去除空格、横线和括号，支持全角数字及中国手机号的 `+86`／`0086` 格式。筛选只在新短信入队前执行，跳过的正文不保存在本 App。

## 消息排版格式（首行高亮验证码）

为保证在飞书、企业微信、钉钉与自定义 Webhook 上都保持轻量稳定，消息统一采用极简纯文本。若短信中提取到验证码，App 会自动将验证码与规则名称提到首行，方便手机锁屏和桌面通知弹窗一眼直读，同时保留“短信转发”关键词兼容群机器人校验：

```text
短信转发｜482910（外卖运营验证码）
接收手机：浦东店·美团号
【美团】您的登录验证码是 482910，5分钟内有效...
发件人：1069xxxx ｜ 21:30:00
```

未提取到验证码的普通短信则以 `短信转发（规则名）` 开头并附完整正文、发件人与接收时间。第二行 `接收手机` 仅在填写了本机号码 / 备注时出现。

## 权限和后台设置

| 项目 | 用途和处理方式 |
| --- | --- |
| 接收短信（`RECEIVE_SMS`） | 监听新到的普通短信，开启自动转发前必须授权。若系统安装器未允许此权限，系统可能无法授权。 |
| 联网（`INTERNET`） | 通过 HTTPS 将消息发送到你配置的目的地 Webhook，系统在安装时授予。 |
| 访问网络状态（`ACCESS_NETWORK_STATE`） | 让系统按网络条件调度发送任务并检查流量限制，系统在安装时授予。 |
| 接收开机广播（`RECEIVE_BOOT_COMPLETED`） | 在开机解锁后恢复后台发送任务，系统在安装时授予。 |

「权限与后台保活」页从系统设置返回时会重新检查状态，并提示电池优化、后台活动、后台流量与厂商自启动等保活项。本 App **不申请**通讯录、通话记录、定位、存储或发送短信权限，也不含任何远程控制能力。

## 国产手机放行与保活 5 步排查

国产手机默认对侧载 APK、验证码短信广播和后台驻留有较严格限制。遇到**装不上、权限灰掉、普通短信能转但验证码转不了、锁屏几小时后漏转**时，按以下 5 步逐项处理：

### 第 1 步：避开微信 `.apk.1` 重命名与安装拦截

- **微信传 APK 被改名**：微信直接发送 `.apk` 文件时会自动在末尾加上 `.1`（例如变成 `sms-forwarder-latest.apk.1`），直接点开无法安装。推荐改用**飞书云文档／飞书群文件**或**手机浏览器**直接下载；如果已经通过微信收到 `.apk.1`，在系统「文件管理」中找到该文件，将后缀重命名回 `.apk` 再点击安装。
- **安装未知应用授权**：在文件管理器或浏览器点击安装时，按提示仅对当前来源应用开启「允许安装未知应用」，装完后可随时关闭。

### 第 2 步：解锁 Android 13–15 侧载「受限制的设置」

在 Android 13、14、15 上，通过浏览器或聊天软件侧载安装的应用，系统可能默认限制敏感权限并把开关置灰：
1. 打开手机**设置 → 应用管理（应用信息）→ 短信转发**。
2. 点击页面右上角的**三个点（⋮）菜单**，选择**允许受限制的设置**（验证锁屏密码或指纹）。
3. 返回「短信转发 → 权限与后台保活」，重新授予短信权限。

### 第 3 步：按手机品牌关闭「验证码安全保护」与放行后台

很多国产 ROM 默认拦截包含验证码字样的短信广播，导致**普通测试短信能转发，真实验证码却收不到**。请按品牌核对：

- **华为 / 荣耀（EMUI / HarmonyOS）**
  - **纯净模式拦截安装**：若纯净模式阻止安装，可在「设置 → 系统和更新 → 纯净模式」中关闭增强防护，或在安装弹窗选择继续安装。
  - **验证码保护**：打开系统**信息 → 右上角设置 → 高级**（或在桌面下拉搜索「验证码」），关闭**验证码安全保护**。
  - **后台保活**：在「设置 → 应用 → 应用启动管理」中找到「短信转发」，关闭自动管理，手动开启**允许自启动、允许关联启动、允许后台活动**。
- **小米 / 红米（MIUI / 澎湃 OS）**
  - **通知类短信权限**：在「设置 → 应用设置 → 应用管理 → 短信转发 → 权限管理」中，除「读取/接收短信」外，务必单独勾选允许**通知类短信**；并确认未开启「空白通行证」。
  - **短信智能识别**：如仍漏验证码，在系统「短信 → 设置」中关闭「免费网络短信」或验证码保护相关开关。
  - **后台保活**：在应用信息里开启**自启动**，并将**省电策略**设为**无限制**。
- **OPPO / 一加（ColorOS）**
  - **验证码保护**：打开系统**信息 → 设置 → 隐私保护**（或安全设置），关闭**验证码安全保护**。
  - **后台保活**：在「应用信息 → 耗电管理」中开启**允许完全后台行为**与**允许自启动**。
- **vivo / iQOO（OriginOS）**
  - **验证码保护**：打开系统**信息 → 设置 → 隐私保护**，关闭**验证码安全保护**。
  - **后台保活**：在「设置 → 电池 → 后台耗电管理」中找到「短信转发」，选择**允许后台高耗电**，并在权限管理中允许**自启动**。

### 第 4 步：通用后台保活与防断网检查

- **锁定最近任务**：打开「短信转发」后切到多任务视图，下拉或点击卡片右上角将其**加锁**，避免一键清理杀掉进程。
- **关闭息屏断网**：检查系统电池或 WLAN 高级设置，确保锁屏休眠时保持移动数据与 Wi-Fi 连接不断开。
- **勿点「强行停止」**：在系统设置中手动点击「强行停止」后，Android 会冻结应用广播接收，需要重新打开一次 App 才能恢复。

### 第 5 步：旧安卓机长期插电作接码机的电池安全建议

许多商家会用闲置旧安卓机 7×24 小时放在工位收验证码。锂电池长期保持 100% 满电直插，几个月后容易出现**电池鼓包甚至起火风险**：
- **开启充电上限（优先）**：若机型系统支持「电池保护 / 充电上限 80% / 旁路供电」，请直接开启。
- **搭配定时插座**：不支持充电上限的旧手机，建议使用几十元的**机械定时插座或智能插座**（例如每天通电 2～3 小时、断电数小时循环充放电），避免 24 小时满电浮充。
- **放置环境**：放在阴凉、干燥、通风且远离易燃物的桌面，每隔一两周检查一次手机背壳是否翘起发热。

## 发送和重试

收到的分段短信合并为一条，附发件人、接收时间与可选的本机号码 / 备注。原始 PDU 和 SIM 订阅共同生成去重指纹；按「短信指纹 + 目的地 ID」维度去重，只保存哈希（最多 2000 个、7 天）。短信暂存在本机 SQLite 私有目录，对应目的地确认成功后删除正文，不保存已成功正文。

断网由系统 JobScheduler 等待网络后重试，指数退避，单条失败 8 次后保留队列，修复配置或网络后点击首页的“重试发送”。单个目的地异常不会阻塞发往其他目的地的消息。另有 15 分钟周期恢复任务，检查待发队列是否需要重新排程；系统可能延迟运行和投递，15 分钟不是送达时限。最多积压 200 条，单条正文上限 16KB，编码转义后的完整请求不得超过 20KB，超过限制提示失败；不会无限消耗存储。较长短信需要在原短信 App 查看。状态只显示最近事件，不显示短信正文。到达上限时后续短信无法转发，应及时处理队列。

暂停会取消后台任务并停止继续发送，已经到达目标机器人的在途请求不能撤回。网络请求成功但回执丢失、进程在确认前退出时，重试可能产生重复消息（Webhook 不支持接收端幂等键），不承诺恰好一次送达。关机重启后，解锁手机后恢复任务；系统省电限制可能延迟后台发送。强行停止 App 后需重新打开。

修改接收群前先暂停并清空队列，避免积压短信误发往新群。清空后不会重读原短信补发。App 配置不是端到端加密，系统 root 或设备解锁权限可能访问本地数据。

## 构建

按[开发指南](development.md)配置环境后，在项目根目录运行。

```bash
cd android
./gradlew testDebugUnitTest assembleDebug lintDebug
```

调试 APK：`android/app/build/outputs/apk/debug/app-debug.apk`。正式版由 GitHub Actions 签名构建并发布到 [Releases](https://github.com/edward-zyz/sms-forwarder/releases/latest)。

协议依据：[飞书自定义机器人指南](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot?lang=zh-CN)、[Android SMS 广播](https://developer.android.com/reference/android/provider/Telephony.Sms.Intents)。本工程仅为自用侧载；应用商店短信权限另有上架限制。
