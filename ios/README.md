# iPhone 短信转飞书

在 iPhone 上使用苹果「快捷指令」的「信息」自动化触发 [短信转飞书.js](短信转飞书.js)。脚本默认不加过滤，通过 Scriptable 发送传入的非空正文。Webhook 和可选签名密钥保存在本机的 Scriptable 钥匙串里。

按[使用手册的 iPhone 章节](../HANDBOOK.md#3-iphone-安装与验证)配置机器人、安装脚本和创建自动化。可按发件人或关键词决定哪些短信触发。请分别测试手动调用、收到短信时的自动化以及锁屏时的表现。

脚本只处理快捷指令提供的文本。系统未触发、断网或请求失败时，需要自行处理漏发。多条自动化同时匹配可能重复推送。正文超过 16,000 字节或序列化后的请求超过 20,000 字节时会报错。

从使用旧配置存储的版本换到公开版后，请在 Scriptable 中直接运行脚本一次，重新保存飞书配置。

在项目根目录执行 `node --test ios/*.test.cjs` 可运行模拟网络测试。
